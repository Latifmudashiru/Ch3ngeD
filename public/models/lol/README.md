# Champion models

Game models are not included in this repository because they are copyrighted by their owners.

To use the Champion Editor, put a rigged `.glb` model here:

```
public/models/lol/aatrox.glb
```

The editor loads `/models/lol/aatrox.glb` by default (see `src/components/lol-studio.tsx`).
Edited results are written to `cache/` in this folder. `.glb` files here are gitignored.
